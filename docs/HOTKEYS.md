# Горячие клавиши

## Глобальная комбинация

По умолчанию:

| Комбинация | Действие |
|---|---|
| **Alt+Space** | Открыть поисковое окно поверх других окон; повторное нажатие скрывает его |

Комбинация регистрируется через Windows `RegisterHotKey` и работает независимо от активного приложения.

## Навигация в окне поиска

| Клавиши | Действие |
|---|---|
| `↓` / `↑` | Следующий / предыдущий результат, с переходом по кругу |
| `PageDown` / `PageUp` | Перемещение на пять результатов |
| `Enter` | Открыть выбранный результат. Если ничего не выбрано, выполнить интернет-поиск по строке |
| `Tab` / `Shift+Tab` | Переключить категорию: Все → Приложения → Файлы → Интернет |
| `Esc` | Закрыть поисковое окно |
| `Ctrl+Backspace` | Очистить строку поиска |
| `Ctrl+P` | Закрепить/открепить выбранное приложение или файл |
| `Ctrl+,` | Открыть настройки |
| Правый клик по результату | Меню: открыть, открыть расположение, скопировать, закрепить |

Ввод текста не сбрасывается при перемещении по результатам. После открытия файла/приложения строка очищается, а последний выбранный элемент запоминается для следующего открытия.

## Полноэкранные приложения

По умолчанию глобальная комбинация **не открывает** лаунчер, когда в фокусе полноэкранное приложение: игра, видеоплеер, презентация или киоск. Это защищает от случайного перекрытия игрового процесса.

Разрешить открытие поверх полного экрана:

**Настройки → Основные → «Показывать поверх полноэкранных приложений»**.

Особенности:

- настройка действует на глобальную горячую клавишу, автозапуск и повторный запуск приложения;
- кнопка **«Открыть поиск»** в меню трея открывает окно всегда, даже при выключенной опции;
- если лаунчер уже открыт, его можно закрыть горячей клавишей независимо от настройки;
- определяется как исключительный D3D-полный экран, режим презентации, так и безрамочное окно без заголовка, занимающее весь монитор;
- обычные максимизированные окна с заголовком и панелью задач не считаются полноэкранными.

## Изменение глобальной комбинации

1. Откройте настройки (`Ctrl+,`, шестерёнка в поиске или меню трея).
2. Нажмите на поле «Горячая клавиша».
3. Нажмите новую комбинацию, например `Ctrl+Alt+K`.
4. Нажмите «Сохранить».

Правила:

- нужен хотя бы один модификатор (`Ctrl`, `Alt`, `Shift`, `Win`) либо функциональная клавиша `F1`–`F24`;
- допускается только одна обычная клавиша;
- `Esc` во время захвата отменяет изменение;
- комбинация регистрируется сразу при сохранении.

## Конфликт комбинаций

Если комбинация уже занята другим приложением, Windows возвращает ошибку `ERROR_HOTKEY_ALREADY_REGISTERED`. Лаунчер:

1. не применяет новую комбинацию;
2. восстанавливает предыдущую рабочую регистрацию;
3. показывает понятное сообщение в настройках.

При старте, если стандартная `Alt+Space` занята, приложение продолжает работать в трее и показывает уведомление. Откройте настройки через иконку трея и выберите другую комбинацию.

Некоторые системные сочетания (`Alt+Tab`, `Ctrl+Alt+Del`, `Win+L` и т. п.) зарезервированы Windows и не могут быть зарегистрированы. Для них также появится сообщение о конфликте.

## Рекомендации

- `Alt+Space` — стандарт Spotlight/PowerToys Run, удобен для привычного использования.
- Если `Alt+Space` занят, хорошие альтернативы: `Ctrl+Alt+Space`, `Ctrl+Shift+Space`, `Alt+\``, `Ctrl+Alt+K`.
- Не используйте сочетание, которое совпадает с горячими клавишами IDE или игры.
