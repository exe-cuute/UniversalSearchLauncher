# Установка Universal Search Launcher

## Системные требования

- Windows 10 x64 (1809 или новее) или Windows 11 x64.
- Для установщика — .NET Framework 4.8 (входит в поддерживаемые Windows 10/11).
- Для установленного приложения отдельный runtime не нужен: используется self-contained сборка .NET 8.

## Обычная установка

1. Запустите `UniversalSearchLauncher-Setup-1.0.1.exe`.
2. При необходимости измените папку установки. По умолчанию:
   `%LocalAppData%\Programs\Universal Search Launcher`.
3. Отметьте нужные параметры:
   - создать ярлык на рабочем столе;
   - запускать при входе в Windows;
   - запустить приложение после установки.
4. Нажмите «Установить».
5. После завершения приложение появится в системном трее. Нажмите **Alt+Space**.

Установка выполняется для текущего пользователя и **не требует прав администратора**. Если выбрать папку в защищённой области (например, `C:\Program Files`), Windows может запросить повышенные права или установка завершится ошибкой доступа.

### SmartScreen

Установщик не подписан сертификатом, поэтому Windows может показать «Windows защитила ваш компьютер». Чтобы продолжить, нажмите «Подробнее» → «Выполнить в любом случае». Для публичного распространения рекомендуется подписать Setup сертификатом Authenticode.

## Автозапуск

Автозапуск настраивается:

- галочкой в установщике;
- переключателем **Настройки → Основные → Запускать вместе с Windows**.

Запись создаётся в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`:

```text
"<путь>\UniversalSearchLauncher.exe" --background
```

При старте с `--background` окно не открывается; приложение работает в трее. Если удалить папку с приложением вручную, запись автозапуска нужно удалить через настройки или деинсталлятор.

## Тихая установка

```bat
UniversalSearchLauncher-Setup-1.0.1.exe /S /DIR="C:\Tools\Universal Search Launcher"
```

Тихий режим использует параметры по умолчанию: ярлык на рабочем столе, автозапуск, без запуска приложения. Код возврата `0` — успех, `1` — ошибка (журнал ищется в `installer.log` рядом с Setup либо в `%LocalAppData%\UniversalSearchLauncher`).

## Портативный режим

Распакуйте `UniversalSearchLauncher-1.0.1-portable.zip` и запустите `UniversalSearchLauncher.exe`.

- Ярлыки и запись автозапуска не создаются.
- Настройки, история и индекс всё равно хранятся в `%LocalAppData%\UniversalSearchLauncher`, чтобы их можно было сохранить между обновлениями.
- Для тестов и разработки каталог данных можно переопределить переменной окружения `USL_DATA_DIR`.

## Удаление

Способы:

1. **Параметры Windows → Приложения → Установленные приложения → Universal Search Launcher → Удалить**.
2. **Пуск → Universal Search Launcher → Удалить Universal Search Launcher**.
3. Запустить `<папка установки>\Uninstall.exe`.

Интерактивный деинсталлятор спросит, удалять ли настройки, историю и индекс. Тихий режим:

```bat
"<папка установки>\Uninstall.exe" /S
```

В тихом режиме пользовательские данные сохраняются. После удаления приложение, ярлыки, запись автозапуска и запись в списке установленных приложений удаляются; папка установки очищается отложенно после завершения процесса.

## Обновление

Поверх установленной версии можно запустить новый Setup — он остановит работающее приложение и обновит файлы. Пользовательские настройки и индекс сохраняются.

Автоматическая проверка обновлений выполняется по необязательному JSON-манифесту, URL которого задаётся в настройках:

```json
{
  "version": "1.1.0",
  "url": "https://example.com/universal-search-launcher/UniversalSearchLauncher-Setup-1.1.0.exe",
  "notes": "Что нового..."
}
```

Кнопка «Проверить обновления» есть в меню трея и в настройках.
